A live, working customer-support chat - the whole thing, running for real, no local setup.

This is a public demo. The operator login below is published on this page, so anyone can read every conversation started here - including yours. Do not type anything real.

What this page is

This page has AGO Chat's own widget embedded on it, exactly the way a real shop would embed it on their own site - one <script> tag, bottom-right corner. Click it, send a message, and it goes to a real backend running on a real server.

From a second tab or another device, sign into the operator console (below) and answer as the support agent - the two sides talk over a real WebSocket connection in real time, the same as they would for an actual shop and an actual customer.

Try it

Two operator logins are on offer below this card - one shared with every visitor here, one a private tenant of your own. Pick either, then:

  1. Open the chat bubble in the bottom-right corner of this page and send a message.
  2. Open the operator console in a new tab: console.reserve-me.ru - sign in with whichever login you picked.
  3. Find your message in the queue, open it, and reply. Watch it arrive back here live.

Is this safe to poke at?

Yes. Every tenant on this deployment is a demo tenant - the seeded shops these pages embed, plus the throwaway ones the button above mints. No real customer has ever been onboarded here, so there is no production data behind any login on this server. AGO Chat is multi-tenant by construction (every row a visitor or operator can reach is scoped to one site), and you can watch that working between the two shop pages - but nothing you send here is production data, and nothing you do here can reach anything that would be.

Safe for the deployment is not the same as private for you, though, and this card would be misleading without saying so: the login above is published, so anything you type into this page's widget is readable by any stranger who signs in with it. Treat this chat as a public one - or press “Get your own tenant” above and use the private one it hands you, which that login cannot reach.

AGO Chat is a portfolio project demonstrating backend concurrency, realtime messaging, and Clean Architecture end to end - source is public. This page and the widget it embeds are both built and deployed as-is from that codebase, not a mockup.
